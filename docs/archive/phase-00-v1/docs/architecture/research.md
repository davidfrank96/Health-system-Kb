# Provider and dependency research evidence

Reviewed 31 October 2026 using public primary documentation. No account credentials, API permission checks, cloud inventory discovery or target probes were used. Evidence establishes documented interfaces, not Kbean-specific availability. URLs can change; recheck versions, quotas and prices at implementation and before spend. No “latest” version is pinned by this research.

## Research limitations

The Kuma API-Documentation wiki URL redirected to the wiki home; a stable administrative API was not established. No assumption of exact historical check event export is made. Auth/App Check API-backed operational metrics, Hashio/Fusion identities, actual QA protocol, provider quotas/prices per workload, DO cross-cloud federation and fixed-egress needs remain unverified. No dependency lockfile or image selection is made; Phase 01 must check OIDC library, SQL/queue library, pnpm, React/Tailwind/Zod/testing tool compatibility and current advisories before installation. This is public interface research, not a claim that every proposed dependency has passed a runtime compatibility test.
