# 0009 · Resource and metric evidence

One PostgreSQL database stores a service-scoped manual assertion or an exact resource-scoped provider reading. The CSV contract identifies a service and provider, which can map to multiple resources. Preserve that scope rather than attributing a reading to an arbitrary resource.

A relational dictionary and resource-capability mapping enforce unit and identity consistency at ingestion. Checked views separate staff and provider provenance. A small daily reservation table serializes outbound budget decisions across resources. Daily metric summaries preserve sample counts and totals separately from the Phase 02 availability denominator. These tables extend the original planning count while retaining one database, one finite job and no additional hosted component.
