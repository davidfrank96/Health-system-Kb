# Deferred providers and components

Hashio and Fusion remain unresolved product names. Obtain exact vendor/product/resource owner, supported interface, effective permissions and zero-incremental-cost evidence before any adapter or request. An approved manual metric may be stored only with known source identity/provenance; do not invent vendor semantics.

Wazuh/Eramba and other security tools remain sources of approved references, optionally supplied through the existing QA contract. No SIEM ingestion, unrestricted logs, new security scanner or paid integration.

Kuma, Prometheus, Grafana, extra Droplets/regions, permanent collectors, HA database, distributed queues, public subscriptions/publishing, separate report engines, external archives and paid notifications are **deferred options only**, not prerequisites. No deployment files, runtime clients or tests for these components belong in MVP. Reconsider only with measured need, budget approval and a new ADR. Runtime AI inference and paid API features are excluded from the current direction.
